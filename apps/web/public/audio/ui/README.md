# UI narration placeholders

Every student screen speaks its prompt on arrival — see
`apps/web/lib/use-screen-narration.ts`, which resolves `{key}.{locale}.mp3` from
this directory.

The files here are **one second of silence**, not recordings. Real narration is
generated by the voice pipeline in implementation file 36; these exist so the
screens are wired to the right filenames now and so a child's device is not
issuing a 404 on every navigation in the meantime.

Replacing one is a data change: drop in a real clip under the same name.

| Key | Screen | English line to record |
| --- | --- | --- |
| `selectProfile` | `/select-profile` | "Who's learning today?" |
| `home` | `/home` | "Pick a world!" |
| `world` | `/world/[worldId]` | "Pick something to play!" |

Each key needs one file per locale (`en`, `bn`).
