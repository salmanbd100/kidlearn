# Security policy

KidLearn is used by young children, so security and privacy reports come first.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/salmanbd100/kidlearn/security/advisories/new).
Include the affected URL or file, the steps to reproduce, and the impact you expect.

You will get an acknowledgement within 72 hours. A fix for anything that exposes a
child's or parent's data takes priority over all other work.

## Scope

- `kidlearn.net`, `api.kidlearn.net` and the code in this repository.
- `dev.kidlearn.net` runs unreviewed builds. Report what you find there, but don't
  treat its data as real.

Please don't run denial-of-service tests, social engineering or automated scanning
that creates load against production.
